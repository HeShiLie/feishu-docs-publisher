# 0.4.1

Fix missing images in research-note exports.

- Render PDF++ page and `rect` embeds as PNG images at their source positions.
- Keep `![[image.png|width]]` inside its Callout/list context and ignore image examples in code.
- Upload directly to pre-created native image blocks; journal file tokens for safe retries.
- Preserve PDF page captions and image dimensions.

Live API tests confirmed the original two PDF crop images and a PNG WikiLink inside a folded parent. General browser fold/unfold visual acceptance remains pending, so this remains a pre-release.

Obsidian uses its bundled PDF.js. Standalone Git hooks require Poppler for PDF image rendering; rotated PDFs should be published from Obsidian. Source Markdown and PDFs stay read-only.

Install by replacing **main.js**, **manifest.json**, and **styles.css** in the existing `feishu-docs-publisher` plugin folder, preserving plugin data. Requires Obsidian 1.13.0+ and the existing CLI authorization, including `docx:document.block:convert`.
