# 0.3.0

## Added

- 在插件设置的「CLI 与授权」中安装或升级 `lark-cli`，查看版本和登录状态。
- 在浏览器中创建飞书或 Lark CLI 应用，并支持登录、重新授权、退出和取消进行中的授权。
- 缺少 npm 时可直接打开 Node.js 下载页，安装后重新检测。
- 新增系统、自定义和关闭三档网络代理，并统一应用到插件启动的 `lark-cli`、npm 和 Git `pre-push` 同步。

## Fixed

- 重新绑定子目录时清除覆盖它的父目录断开标记。
- 远端 PDF 被删除或移动后重新上传并更新绑定。

**完整变更**：https://github.com/totok22/feishu-docs-publisher/compare/0.2.1...0.3.0
