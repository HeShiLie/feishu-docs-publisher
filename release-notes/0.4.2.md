# 0.4.2

Native research exports now render explicitly bold labels immediately before `:` or `：` using a bright yellow background and red text. Bold and other inline styles are retained; unrelated bold text and code remain unchanged.

Examples: `**Task**:` and `**特点**：`. The colon itself is not additionally colored.

Includes the 0.4.1 PDF crop and WikiLink image fixes. Source Markdown remains read-only. This remains a pre-release; the broader visual fold/unfold acceptance status is unchanged.

Replace the three standard plugin assets while preserving plugin data.
