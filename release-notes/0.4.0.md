# 0.4.0

First research-export pre-release of this fork, based on totok22/feishu-docs-publisher 0.3.1.

## Changes

- Export Callouts as native parent/child trees while keeping the main narrative in place.
- Preserve nested content, initial fold states, and colored title rows.
- Keep PDF citation labels and page numbers; report unresolved attachments.
- Add journaled, idempotent subtree synchronization and remote-edit protection.
- Keep source Markdown read-only, including binding/deletion handling.

## Install

Download the three standalone assets below: **main.js**, **manifest.json**, **styles.css**.
Place them in `<vault>/.obsidian/plugins/feishu-docs-publisher/` with the plugin disabled, preserve existing plugin data, then restart Obsidian.

Requires desktop Obsidian 1.13.0+ and configured lark-cli. Native export additionally needs `docx:document.block:convert` authorization.

This fork retains the upstream plugin ID for replacement compatibility. Do not enable it alongside the upstream plugin. It is not a separate Obsidian community-directory listing.

## Validation and limits

Automated tests and production build pass. Live API tests confirmed nested block structure, source-file preservation, unchanged-export skipping, and targeted subtree replacement.

**Visual fold/unfold acceptance remains pending.** This is a pre-release, not a claim of full Obsidian rendering fidelity. PDF crop images and exact selection navigation are not implemented. Network images and native changes above 1000 blocks are rejected. Live local-image-in-Callout coverage and Mermaid/table/footnote/HTML compatibility are incomplete. Changed subtrees can receive new block IDs and lose comment anchors within the replaced range.

See [compatibility details](https://github.com/HeShiLie/feishu-docs-publisher/blob/main/docs/native-export-v2.md).
